Description: 

Designed and developed an interactive Tableau dashboard to track confirmed COVID-19 cases, recoveries, fatalities, and vaccination rates across Indian states. Used choropleth heat maps, trend lines, and dual-axis charts to visualize infection growth, mortality rates, and recovery trends over time. Analyzed key pandemic milestones and vaccination coverage gaps, presenting the findings in a public-awareness report to support data-driven public health discussions.
